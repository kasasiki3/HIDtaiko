各項目の説明Parameters

感度

各センサーの反応閾値です。値が低いほど感度が高くなります。黄色の範囲が推奨値です。多重入力が発生する場合は値を大きくしてください。

Sensitivity

Threshold for each sensor. Lower value = higher sensitivity. The yellow zone is the recommended range. Increase the value if phantom inputs occur.

縁ディレイ

縁を連続で叩いたときに多重入力が起きる場合に大きくしてください。大きすぎると縁の連打が鈍くなります。

Rim Delay

Increase if consecutive Rim hits cause phantom inputs. Too high will slow down Rim rolls.

面ディレイ

面を連続で叩いたときに多重入力が起きる場合に大きくしてください。大きすぎると面の連打が鈍くなります。

Don Delay

Increase if consecutive Don hits cause phantom inputs. Too high will slow down Don rolls.

縁面相互ディレイ

面を叩いたときに縁が反応する、または縁を叩いたときに面が反応する場合に大きくしてください。

Cross Delay

Increase if hitting Don also triggers Rim, or vice versa.

公式/シミュレーター向け

公式アプリや一部のシミュレーターでキーが認識されない場合はONにしてください（Hdelay=20ms が適用されます）。

Official/Simulator

Turn ON if key inputs aren't recognized in the official app or some simulators (applies Hdelay = 20 ms).

Cdelay Std: 13 ms

Same as Bdelay but for Rim (edge) hits.

Ddelay 標準: 10 ms

面入力後に縁入力を制限する時間（逆も同様）。面を叩いたときに縁が多重する場合や、その逆の場合に値を上げてください。

Ddelay Std: 10 ms

Time to suppress Rim input after a Don hit (and vice versa). Increase if a Don hit also triggers a Rim, or vice versa.

Hdelay 標準: 20 or 0 ms

公式アプリや一部シミュレーター向けの入力制限。「メモ帳では入力できるがシミュレーターでは入力できない」場合に設定してください。

Hdelay Std: 20 or 0 ms

Input throttle for the official app or some simulators. Set this if inputs work in Notepad but fail in a simulator.

Switch 押下時間 標準: 25 ms

Switchモードでの1打あたりのボタン押下時間です。短くすると連打が入りやすくなりますが、短すぎるとSwitch側が打を取りこぼします。20ms未満は非推奨です。

Switch Hold Std: 25 ms

Button hold duration per hit in Switch mode. Shorter values make rolls easier, but too short causes the Switch to drop hits. Values below 20 ms are not recommended.

Switch 入力分散 標準: 2系統

1打ごとに使用するボタンを切り替えて、連打の上限を引き上げる機能です。通常は「2系統」のままにしてください。

Switch Spread Std: 2 buttons

Rotates the button used for each hit to raise the roll speed cap. Normally keep it on "2 buttons".

Switch USB識別子 標準: HORIPAD S

Switchに対して名乗るコントローラの種類です。通常は変更不要です。Switch 2 で認識されない場合のみ他の値を試してください。変更後はUSBを挿し直してください。

Switch USB ID Std: HORIPAD S

The controller type reported to the Switch. No change is normally needed. Try other values only if the Switch 2 doesn't recognize it. Re-plug the USB after changing.

感度調整のやり方Tuning Guide
  1. 感度スライダーを黄色の範囲内に設定する（初期値の目安）
  2. 実際に演奏して強打・弱打が確実に反応するか確認する
  3. 多重入力（1打で複数反応）が起きる場合は、該当するディレイを少しずつ大きくする
    • 縁で多重入力 → 縁ディレイを上げる
    • 面で多重入力 → 面ディレイを上げる
    • 面を叩いたとき縁が反応 → 縁面相互ディレイを上げる
  4. 調整が終わったら「感度送信」で書き込む
  1. Set sensitivity sliders within the yellow recommended range as a starting point
  2. Play and verify both strong and light hits register correctly
  3. If phantom inputs occur, slightly increase the corresponding delay:
    • Rim double input → increase Rim Delay
    • Don double input → increase Don Delay
    • Don hit also triggers Rim → increase Cross Delay
  4. When done, click "Send" to apply the settings
  1. 感度設定 強打・弱打どちらも確実に反応する中で、できるだけ値を大きく（感度を低く）設定する。
  2. Delay 調整 — 以下の順で、誤反応しない範囲でできるだけ小さい値に絞る。
    • Ddelay：面を叩いたとき縁が反応しなくなる最小値
    • Bdelay：片方の面を強打したときもう一方の面が反応しなくなる最小値
    • Adelay：同じセンサーが1打で2連発しなくなる最小値
    • Cdelay：Adelay・Bdelay と同様に縁用で調整

補足 — サイトの初期値はおおよその目安です。感度を上げると（値を小さくすると）クロストークが増え Delay を増やす必要があります。逆に感度を下げると（値を大きくすると）Delay を短くできます。

  1. Sensitivity Find the highest value (lowest sensitivity) that still reliably registers both strong and light hits.
  2. Delay tuning — In the order below, minimize each value while eliminating phantom inputs.
    • Ddelay: minimum value at which a Don hit no longer triggers a Rim
    • Bdelay: minimum value at which a hard Don hit no longer triggers the opposite Don
    • Adelay: minimum value at which a single hit no longer double-fires on the same sensor
    • Cdelay: same as Adelay / Bdelay but for Rim hits

Note — The default values on this site are rough guidelines. Raising sensitivity (lower value) increases crosstalk and requires higher delays. Lowering sensitivity (higher value) allows shorter delays.

キー配置

HIDtaikoはコントローラーの配置を採用しています。右縁はA、右面はB、左面は→、左縁は←です。

押下時間 — 1打あたりボタンを押しておく長さ。短いほど連打が入りますが、短すぎるとSwitchが打を取りこぼします（20ms未満は非推奨）。
入力分散 — 1打ごとに使うボタンを変えて連打の上限を上げる機能。通常は「2ボタン」のまま。
USB識別子 — Switchに名乗るコントローラの種類。Switchに認識されないときだけ他を試してください。変更後はUSBの挿し直しが必要です。

The device also works as a Switch TaTaCon. Sensitivity and delay are shared with PC mode.

HowSwitching modes
Mode switchThe slide switch on the board (ver1.3 and later only). Switch it, then connect to Switch to be recognized as a Pro Controller.
SiteChoose Startup mode under "Sensitivity", then press Send to save and switch. On boards with SW1 this only applies while SW1 is on the PC side

Key layout

HIDtaiko uses a controller layout. Right rim is A, right face is B, left face is →, and left rim is ←.

Hold — how long each hit holds the button. Shorter lets faster rolls through, but too short and the Switch drops hits (under 20 ms is not recommended).
Spread — rotates which button each hit uses to raise the roll ceiling. Leave it on "2 buttons".
USB ID — which controller the device claims to be. Only try the others if Switch does not recognize it; re-plug the USB after changing.

ファームウェアのアップデートFirmware Update

接続器をDFUモードへ切り替え、V1.3ファームを書き込みます。 Enters DFU mode and flashes V1.3 firmware.

  1. 「接続」を押して、更新する接続器を選択します。すでに接続済みなら不要です。
  2. 「V1.3ファームを書き込む」を押します。
  3. 接続器がDFUモードで再起動し、エクスプローラーに RPI-RP2 ドライブが表示されます。
  4. 「もう一度このボタンを押してください」と表示された場合は、同じボタンをもう一度押し、表示された RPI-RP2 ドライブを選択します。初回のドライブ選択には、ブラウザの操作制限のため再クリックが必要です。
  5. 「完了しました」と表示され、接続器が再起動したら更新完了です。更新後は感度を調整してください。

RPI-RP2 は書き込み専用の一時ドライブです。INDEX.HTM と INFO_UF2.TXT が見えていれば、正しいドライブです。

  1. Click “Connect” and select the connector to update.Skip this if it is already connected.
  2. Click “Flash V1.3 firmware”.
  3. The connector reboots into DFU mode and an RPI-RP2 drive appears in Explorer.
  4. If the page says “click the button once more”, click the same button again and select the RPI-RP2 drive.The browser requires this second click before the first drive selection.
  5. Updating is complete when “Done” appears and the connector restarts. Re-tune the sensitivity afterward.

RPI-RP2 is a temporary drive for flashing. It is the correct drive when it contains INDEX.HTM and INFO_UF2.TXT.

自動更新できない場合

  1. 接続器の基板を取り出し、BOOTボタンを押したままUSBを挿します。
  2. エクスプローラーに RPI-RP2 ドライブが表示されたことを確認します。
  3. V1.3ファームをダウンロードします。
  4. ダウンロードした hidtaiko_v13.uf2 をRPI-RP2ドライブへドラッグ＆ドロップします。接続器が再起動したら完了です。

If automatic updating is unavailable

  1. Open the connector and connect USB while holding the BOOT button.
  2. Confirm that the RPI-RP2 drive appears in Explorer.
  3. Download V1.3 firmware.
  4. Drag and drop hidtaiko_v13.uf2 onto the RPI-RP2 drive. Updating is complete when the connector restarts.
